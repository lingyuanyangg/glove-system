# Glove Neural Scope

[下载 Neural Scope](Glove%20Neural%20Scope.zip) · [英文说明](README.md)

使用左手／右手／双手姿态，同时学习并控制**多个 Ableton 设备的参数**，支持同轨道、Rack 内设备和跨轨道目标。一次 Capture 采集所有目标参数，一个模型联合输出。界面保持 Ableton 风格，主面板 1060 × 169，↗ 打开大编辑器。

安装 FluidCorpusManipulation／FluCoMa，保留 `Glove_Neural_Scope` 内 AMXD、JS 和 HTML，加载到音频轨道或乐器后面。已打开的旧实例需要重新加载才能使用新版。先连接并校准 [Receiver](../receiver-v2/README_中文.md)。

## 添加多个设备

1. **This track** 浏览设备所在轨道；**Selected track** 浏览 Live 选中轨道。Follow 跟随当前轨道的选中设备，用于浏览；手动选择设备会关闭 Follow。
2. 首个选中的设备自动加入目标。浏览下一个设备，点击 **Add**，再在 Scope 中开启需要学习的参数。后续新设备默认 Scope 全关；Device On 默认排除。
3. 继续添加其他设备。跨轨道时使用 Selected track 浏览后再 Add；已加入的目标会保留，不会因为切换浏览轨道而被替换。
4. **Targets** 查看完整目标列表、每个设备的输出数量，并可 View 或 Remove。顶部 Remove 移除当前浏览设备。All／None／First 10 只作用于当前设备。

最多 **32 个目标设备、合计 256 个参数输出**。Output 按设备加入顺序、再按设备参数表顺序统一编号。参数未暴露时，可用插件的 Configure。移除目标会保留它的设置和已有训练库。

## 采样、训练和运行

选择 Left／Right／Both。Run 关闭时，摆手套姿态，同时设置所有目标设备的声音，再点击一次 **Capture**。一个样本包含手套数据与全部目标参数。建议先采集 8–20 个不同姿态／声音，至少两个；每库最多 512 个，近似重复姿态会被拒绝。

**Train → Run** 后联合控制所有目标。RMSE 是训练误差，应再用新姿态检查效果。**Stop** 释放所有设备的全部参数映射。改变目标集合、输入模式或 Scope 会停止控制；仅浏览设备／轨道不会丢失已添加的目标。


**Delay s** 默认 5 秒，可设 0–15。先设置声音，点击 Capture，再利用倒计时摆好双手，到时只采集一个样本，同时读取全部目标的 Scope 参数值。设为 0 可立即采集。Stop 取消；改变目标集合、输入模式、Scope 或输出范围也会取消。等待时仍可调整声音值。延时采集要求所选手的数据在 300 ms 内，双手到达时间差不超过 80 ms；输入失效会取消。每个新姿态／声音都单独点击 Capture。Train 使用已有样本，训练时无需保持姿态。Delay 随 Set 保存，恢复时不继续倒计时。

每个“有序目标集合＋输入模式＋合并 Scope”有独立训练库。返回相同配置可取回之前的库。增加／删除样本后需要重新训练；给旧模型增加设备输出，也需要重新采集并训练。

Min／Max 是各参数原生单位的输出限制，不是重新缩放模型。Smooth 默认 30 ms，可调 0–500 ms。运行时映射会接管参数，Stop 后恢复 Live 自身参数值。任一目标被删除、移动或改变参数列表时，会停止整个目标集合的控制。缺失目标会明确保留，不会静默从模型中删掉；必要时移除后重新加入并检查 Scope。

## 模型选择与保存

训练后输入名称并 Save，在 MODEL 中选择并 Load，恢复目标设备列表、样本、权重、Scope 和范围，Run 保持关闭。输入模式必须一致，Load 会检查所有目标路径和参数结构。最多 128 个命名模型。

保存 Live Set 保留目标集合、模型、训练库和设置。Export／Import JSON 转移模型；× 删除快照，不清空工作库。重新排列或替换设备后，先核对目标，尤其是多个相同设备。旧单设备 Set 数据和模型仍可使用；旧命名模型需要单个兼容目标。原始 FluCoMa JSON 按当前合并 Scope 顺序绑定输出；Data Knot 5 输入／10 输出模型需要单手和合计十个输出。

手指顺序为小指、无名指、中指、食指、拇指；双手按左五项＋右五项拼接。本设备保留两手最近的有效值，没有独立逐手超时或双手时间差检查，断开手套前请 Stop。
