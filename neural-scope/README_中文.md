# Glove Neural Scope

根据原 `reressorMapping2` 的 neural regression 与 Scope Lab 参数设备重建的 Max for Live Audio Effect。使用手套姿态学习一个目标设备的多个参数；支持 **左手／右手／双手**，并采用紧凑的 Ableton 风格界面。

## 安装和输入

解压整个 `Glove Neural Scope.zip`，保持 `.amxd`、`neural_scope_control.js`、`neural_scope_ui.html` 和 `gloveRegressor10.json` 在同一文件夹。将 `.amxd` 拖入音频轨道，或 MIDI 轨道的乐器后方。音频为立体声直通。

它从 Max 的 **`GLeft`／`GRight`** 接收数据，不额外绑定 OSC 端口。先加载此前的 Glove Receiver Dual：左手 UDP 7000、右手 UDP 6000。单手为 5 维输入；双手为 **左手五值 + 右手五值** 的 10 维输入。每只手顺序均为小指、无名指、中指、食指、拇指，数值范围 0–1。

双手模式必须两只手都收到过有效数据。设备加载后，手指移动一次以收到初始值；未收到的手不会用零填充。`GLeft`／`GRight` 没有连接心跳，稳定姿态以及停止收包时均保持最近的有效值。

## 目标设备和参数

- **This track**：本设备所在轨道，包含 Rack 链内部设备；默认模式。
- **Selected track**：Live 当前选中的轨道，随轨道选择变化。
- **Follow**：跟随所选轨道当前选中的设备。点击本设备自身不会清除已选目标。
- TARGET 下拉框：固定到一个设备，同时关闭 Follow。
- **↗**：打开更大的编辑窗口，查看和编辑完整参数表。

Scope 选择参与学习的参数，Output 显示它在回归输出中的编号。默认排除 Device On；最多同时映射 256 个参数。All／None／First 10 可批量选择。第三方插件只列出暴露给 Live 的参数，必要时使用 Configure。

Min／Max 是输出限幅，使用 Live API 内部单位；悬停 Live value 可看宿主格式化的数值。它们不会重新缩放已学到的音色。离散参数吸附到整数档位，自定义范围必须包含有效档位。

## 学习流程

1. 选择 Left、Right 或 Both，以及目标设备和 Scope 参数。
2. 保持 **Run 关闭**。摆出一个手势，调整目标设备到希望对应的音色，按 **Capture**。
3. 用不同手势和音色重复记录。建议先记录 8–20 个样本，至少两个不同姿态；每个 bank 最多 512 个样本。过于接近已记录姿态的样本会被拒绝。
4. 按 **Train**。Epochs 默认 800，可设 50–5000；训练分批调度，可以取消。显示的 RMSE 是训练集误差，不代表新手势上的准确率。
5. 按 **Run**，手套数据会通过神经网络同时控制所有 scoped 参数。**Stop** 释放全部参数接管。

每个目标、手部输入模式、所选参数结构拥有独立的训练 bank。切换 Scope 会选择另一个 bank，再切回原 Scope 会取回它的样本和模型。增加、撤销或清除样本后，需要重新训练。改变目标、轨道或输入模式会停止 Run；不会自动接管新目标。

训练采用内置 ES5 MLP：**5 或 10 → 16（tanh）→ 所选参数数目（linear）**，使用 Adam 更新权重；预测输出限制为 0–1，再转换到参数的原生范围并限幅。不依赖额外的 Data Knot／FluCoMa 安装。

## 原有 neural regression 模型

选择 Left 或 Right，并且正好 Scope **10 个参数**，按 **Legacy model**，即可加载原 `gloveRegressor10.json` 的 **5 → 3 → 3 → 10** 权重和十组样本。输出 1–10 按 scoped 参数在表中的顺序分配。

原模型只接受五维输入，不能直接用于 Both。它原先的训练输出是十个通用归一化数值，不包含目标设备参数身份；换到新的设备时应检查输出顺序和音色，或重新捕捉、训练。

## 防抖、接管和保存

输入沿用 Dual receiver 已有的死区／时间平滑，输出再使用默认 **30 ms** 的 `live.remote~` 平滑，可设 0–500 ms。

Run 时目标参数由 `live.remote~` 接管，直接编辑和相关自动化暂时不可用；Stop 后释放，Live 的底层基础值重新生效。运行不会为每个实时变化添加撤销记录。Capture、范围和数值编辑在 Run 时不可用。

样本、训练权重、Scope、限幅和设置以 Blob 保存到 **Live Set**，需要保存 Set 才能持久保留。重新加载时 **Run 始终关闭**；手套实时数值不保存。关闭 Follow 的目标需要重新从 TARGET 选择。保存按轨道／设备／Rack 链位置和参数结构重匹配；大幅重排或用同结构设备替换后，请检查目标。

## 界面和验证

主界面为 1060 × 169，采用灰色扁平控件和橙色状态；接入 `live.colors` 以更新深／浅主题。界面使用本地 `jweb`，没有外部网页、字体或网络服务依赖。

离线神经网络、Live API 适配器、分段状态传输、主题和设备结构检查已通过。**这版尚未在 Live 原生宿主或实物手套上实测**；浏览器预览访问被拒绝，Live 界面控制也未获授权。具体范围见 `VALIDATION.md`。
