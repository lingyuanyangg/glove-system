Learn gestures → device parameters

Select This track for the utility’s own track, or Selected track for Live’s currently selected track. Follow follows that track’s selected device. Choosing the TARGET menu pins a device and disables Follow. Changing target or input mode stops control; enable Run again explicitly.

Select Left / Right / Both and choose the parameters to include in Scope. With Run off, make a glove pose, adjust the target sound, and press Capture. Repeat with different poses and sounds, then press Train. Start with 8–20 distinct examples; at least two are required. Turn Run on to predict and control all scoped parameters together.

Single-hand input has 5 values; Both concatenates Left then Right for 10 values. Finger order is pinky, ring, middle, index, thumb. Both hands must have sent a valid frame. The source is Max GLeft / GRight, supplied by the Dual receiver. A stationary frame is held; these buses do not provide a connection heartbeat.

Every target, input mode, and scoped-output structure has an independent bank. Changing Scope selects another bank without deleting the previous one. Adding/removing examples invalidates the current trained model. Training runs in small scheduled chunks. The RMSE shown is training error, not unseen-gesture accuracy.

Min / Max are output clamps in Live’s internal units. They do not rescale the learned sound. Quantized parameters snap to available integer steps. Device On is excluded initially. Parameters controlled elsewhere cannot be captured or taken over. Capture and editing are disabled during Run.

Each Run uses native live.remote~: mapped parameters are temporarily unavailable for direct editing and automation. Stop releases all mappings; Live’s underlying base values become active again. Output smoothing defaults to 30 ms. This complements the receiver’s input jitter filter.

Models: after training, enter a model name and press Save. Choose a snapshot in the model selector and press Load; its scoped parameters and output bounds are restored with Run off. Named snapshots are independent of the working training bank and are saved with the Live Set. Export writes the chosen snapshot as JSON; Import adds a previously exported file to the selector and loads it if compatible. Use × to remove a snapshot. Input hand mode and target parameter structure must match. Import can also read a user-selected Data Knot 5 → 10 JSON with a single hand and exactly ten scoped outputs; those files bind outputs in table order. No preset model is bundled or loaded automatically.

Samples, trained weights, ranges and settings are saved with the Live Set. Run is always off after restore. Reordering or replacing tracks/devices can change saved structural paths; review the target before running. Only parameters exposed to Live are listed; use a plugin’s Configure if needed. Up to 256 outputs and 512 examples per bank.
