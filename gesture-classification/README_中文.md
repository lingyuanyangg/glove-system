# Glove Gesture — 手套手势分类器

用于 **ElastremeSense Manu-5D e-skin data glove kit** 项目的独立 Max for Live 设备。支持 **左手、右手、双手**，识别六种自定义手势，并触发映射的 Ableton 设备按钮。

UI 内置张手、握拳、食指伸出、V 字、中指伸出、OK 六张原创手部线图。左手模式镜像图形；右手模式显示另一朝向；双手模式显示成对图形。双手模型学习左右手组合的十维输入，不要求两只手做相同动作。

## 安装与操作

1. 保持 `Glove Gesture.amxd`、`.maxpat`、`gesture_control.js`、`gesture_ui.html`、`gesture_help.html`、`gesture_help_path.js` 在同一文件夹。把 AMXD 放到音轨或乐器后；音频为立体声直通。
2. 在 Max Package Manager 安装 FluCoMa / FluidCorpusManipulation。本机已安装并检查 **1.0.9**。运行双手接收器，确保发送到 `GLeft` / `GRight`；分类器不额外占用 UDP 端口。
3. 选择 Left / Right / Both。每种模式有独立训练数据与模型。输入顺序为小指、无名指、中指、食指、拇指；双手为左五值后接右五值。训练与运行使用相同的校准及滤波设置。
4. 摆好手势，点击对应卡片 **+ Rec**，保持两秒。每 50 ms 最多记录一次新数据。建议每个手势重复 5–10 次，包含轻微自然变化。单类最多 400 个样本。
5. 点击 **+ Other**，录制放松及手势间的过渡动作。每个启用手势和 Other 至少需要 20 个样本；不想训练的手势可以取消勾选。这个最低数量只是操作门槛，不保证准确率。
6. 点击 **Train**，完成后先不映射按钮，打开 **Run** 检查新的动作重复。稳定识别后卡片亮起。训练误差不是独立测试准确率；尤其检查食指、V、中指及 OK 是否混淆。
7. 关闭 Run，点击手势下方原生 **Map**，再点击 Ableton 的双状态设备参数按钮，例如效果器 Device On/Off。× 取消映射。开启 Run 后由稳定手势触发动作。

OK 图示画出拇指与食指接触，但现有五指弯曲数据不能直接测量接触。模型只能学习弯曲模式；不同动作若产生相同传感器数值，就无法可靠区分。设备没有预训练模型，需要使用你的手套录制样本。

## 按钮动作

| UI | 行为 |
| --- | --- |
| Toggle | 进入手势时切换一次；持续保持不重复触发 |
| Pulse | 开启后，经过 Pulse 时间关闭；Stop 提前释放 |
| Hold | 保持已确认手势期间开启；退出、停止或数据丢失时关闭 |
| On | 进入手势时开启，退出后保持该状态 |
| Off | 进入手势时关闭，退出后保持该状态 |

可映射两状态 `DeviceParameter`，以及插件暴露为非量化 0–1 参数的开关。其他范围的连续参数和多状态枚举会被拒绝。这里的 Map 不支持任意界面按钮、播放/录音、Clip Launch 或轨道 arm/mute/solo；这些需要单独的 Live API/MIDI 接口。

Pulse / Hold 结束时写入按钮低值，不恢复之前的状态。临时保持期间若按钮被手动改离高值，释放时不覆盖该修改。多个手势映射同一按钮时，后续动作覆盖之前的临时释放任务。映射改变会停止 Run。

## 防抖与未知动作

- **Hold = 120 ms**：新分类必须持续稳定才确认，过滤短暂抖动。
- **Gap = 350 ms**：两次进入触发的最小间隔。持续保持同一手势只触发一次；需经过 Other 或另一手势才能再次进入触发。
- **Pulse = 120 ms**：脉冲持续时间；后台每 25 ms 检查释放。
- **Radius = 0.18**：预测类别到其最近训练样本的归一化手指 RMS 距离阈值，超出就视为 Other。它不是置信概率，也不能保证拒绝所有未知动作。
- 单手帧超过 300 ms 视为过期；双手到达时间差需不超过 80 ms。数据缺失会释放临时状态，清除识别；Run 在有效数据恢复后继续识别。异常数据会关闭 Run。
- Stop、换手、加载模型及修改设置，会使旧的异步预测失效。

## 保存与模型选择器

训练后填写 Model name，点击 **Save**。选择已保存模型并 **Load**；必须处于该模型对应的手模式。模型保留启用类别、样本、权重及训练误差，加载后 Run 关闭。

保存 Live Set，可保存三种训练库、最多 64 个模型快照、按钮动作和防抖设置。原生 Map 组件负责保存映射身份。**Export / Import** 用 JSON 在不同 Set 之间传递模型及样本，不携带 Live 按钮映射。分类模型与之前的回归/Data Knot 模型格式不同，不能混用。

## Max 输出

- 左手：`r GGestureLeft`
- 右手：`r GGestureRight`
- 双手组合：`r GGestureBoth`

格式为 `enter <label> <number>`、`exit <label> <number>`。张手 `open` 1，握拳 `fist` 2，食指 `index` 3，V `v` 4，中指 `middle` 5，OK `ok` 6。Other 不触发；Stop 和输入丢失会为活动手势发送 exit。多个设备实例共用这些输出总线。

原生 FluCoMa 负责神经网络训练和推理。协议、防抖、映射、模型及补丁结构有离线验证；实际 Max/Live 加载、界面、映射保存与真实手套准确率仍需在宿主中测试。详见 [VALIDATION.md](VALIDATION.md)。
