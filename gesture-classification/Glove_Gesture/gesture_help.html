Glove Gesture

A trainable hand-pose classifier for your ElastremeSense Manu-5D glove system.

1 · Choose the hand input

Run the dual glove receiver first. This device listens to GLeft and GRight. Left and Right each use five finger values. Both uses ten values to learn a paired pose. Each mode has its own training bank. The images are pose references; Both does not require identical poses on the two hands.

2 · Record your own gestures

Choose a pose and press + Rec. Hold it for two seconds while the glove sends data. Repeat 5–10 times with small variations. Record Other several times, including relaxed poses and transitions. Disable a gesture’s checkbox if you do not want to train it. Train requires at least 20 samples for every enabled gesture and for Other.

The OK illustration shows contact between thumb and index finger. The glove inputs contain bend values, so the model learns the bend pattern; it cannot directly detect contact or hand position.

3 · Train and test

Press Train, then Run. Try new repetitions before mapping actions. The confirmed card lights up. The training error is not an accuracy score. Radius rejects a pose too far from recorded samples; it is not a confidence probability or a guarantee that every unknown pose is rejected.

4 · Map a button

Turn Run off. Click the native Map control under a gesture, then click a two-state parameter in Live, for example Device On/Off or an effect switch. Use × to unmap. Mappings are restored with the Live Set by the native component. Only exposed DeviceParameter buttons can be mapped here; transport, clip launch and arbitrary interface controls require separate integrations.

  • Toggle: invert the button once when the gesture is confirmed.
  • Pulse: set the button on, then off after the Pulse interval.
  • Hold: on while the confirmed gesture is held; off on exit, Stop or missing data.
  • On / Off: write a fixed button state when the gesture is entered.

Holding a gesture does not repeat triggers. A new gesture must remain stable for Hold milliseconds, and Gap limits successive triggers. Pulse and Hold use the parameter’s low/high values; they do not restore its previous value. If a temporary output was manually changed away from On, release does not overwrite it.

5 · Save models

Enter a name and press Save. Select a saved model and Load it in its matching hand mode. Save the Live Set to retain all banks, models, actions and native mappings. Export/Import JSON shares a model and its examples between Sets. Exported models do not include Live button mappings. Run always returns off after recall.

Max output

r GGestureLeft, r GGestureRight, or r GGestureBoth receives enter <label> <number> and exit <label> <number>. Gesture numbers are Open 1, Fist 2, Index 3, V 4, Middle 5 and OK 6.
