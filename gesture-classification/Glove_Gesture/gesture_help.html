Glove Gesture

A trainable hand-pose classifier for your ElastremeSense Manu-5D glove system.

1 · Choose the hand input

Run the dual glove receiver first. This device listens to GLeft and GRight. Left and Right each use five finger values. Both uses ten values to learn a paired pose. Each mode has its own training bank. The images are pose references; Both does not require identical poses on the two hands.

2 · Choose and record a pose

Use the training dropdown. Left/Right show one selected gesture. In Both, choose a different pose for each hand if desired, then Record 2s captures them as one ten-dimensional combination. Repeat several times with small variations and record Other/transition examples. Only enabled recorded classes participate in training; at least 20 samples per enabled class and Other are required.

Run replaces the selected-pose picture with the detected gesture or left/right combination. Confirming means the Hold guard is pending; Confirmed means the active trigger. Other displays an unknown marker.

3 · Train and test

Press Train, then Run. Try new repetitions before mapping actions. The pose status changes to Confirmed. The training error is not an accuracy score. Radius rejects a pose too far from recorded samples; it is not a confidence probability or a guarantee that every unknown pose is rejected.

4 · Map a button

Open Mapping. Browse Left/Right/Both assignments, then click a row’s Map control, then click a two-state parameter in Live, for example Device On/Off or an effect switch. Use × to unmap. Each of 48 target slots uses a persistent native live.object. Both defaults to recorded pairs; Show all combinations exposes all 36 ordered pairs. Only exposed DeviceParameter buttons can be mapped here; transport, clip launch and arbitrary interface controls require separate integrations.

  • Toggle: invert the button once when the gesture is confirmed.
  • Pulse: set the button on, then off after the Pulse interval.
  • Hold: on while the confirmed gesture is held; off on exit, Stop or missing data.
  • On / Off: write a fixed button state when the gesture is entered.

Holding a gesture does not repeat triggers. A new gesture must remain stable for Hold milliseconds, and Gap limits successive triggers. Pulse and Hold use the parameter’s low/high values; they do not restore its previous value. If a temporary output was manually changed away from On, release does not overwrite it.

5 · Save models

Enter a name and press Save. Select a saved model and Load it in its matching hand mode. Save the Live Set to retain all banks, models, actions and native mappings. Export/Import JSON shares a model and its examples between Sets. Exported models do not include Live button mappings. Run always returns off after recall.

Max output

r GGestureLeft, r GGestureRight, or r GGestureBoth receives enter <label> <number> and exit <label> <number>. Single-hand numbers are Open 1, Fist 2, Index 3, V 4, Middle 5 and OK 6. Combined labels use left__right; numbers are 1 + leftIndex × 6 + rightIndex (zero-based), e.g. fist__v 10.

Upgrade: reload the AMXD and review/remap buttons. Version-one Both labels migrate to same-name pairs while preserving weights; old mixed-hand meanings cannot be recovered from the label metadata.
